# SaaS Subscription Platform

A full-stack SaaS platform starter built with Spring Boot, PostgreSQL, JWT Auth, and Stripe.

## Tech Stack

- Java 21, Spring Boot 3.5.0
- Spring Security (JWT Auth)
- PostgreSQL
- Stripe or Razorpay for billing (coming soon)
- React (Frontend - coming soon)

## Getting Started

1. Clone the repo  
2. Set up PostgreSQL locally  
3. Update `application.properties` with your DB credentials  
4. Run the Spring Boot app  
5. Explore the `http://localhost:8080` endpoint (API only for now)
